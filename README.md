# ДЗ 3: логистическая регрессия и Streamlit

**Опубликованное приложение:** [Wine Quality](https://wine-quality-3gkpzaqhgfu5jtyl9vo3be.streamlit.app/). Публичный интерфейс проверен 7 ноября 2026 года без входа в аккаунт.

## Что сдавать

- `HW3_MMDA_completed.ipynb` — заполненный ноутбук с выполненными ячейками, таблицами, шестью графиками и выводами.
- `wine_app/` — приложение, обученный пайплайн, конфигурация, тестовая выборка, пример CSV и инструкция.
- `Data/wine_quality.csv` — исходный файл из приложенного архива; интернет для получения данных не нужен.
- `results_summary.csv` и `validation_summary.csv` — итоговые таблицы для проверки чисел.
- `tests/` и `validation_report.json` — дополнительные проверки.

## Окружение и ноутбук

Проверено с Python **3.12.14**. Рекомендуется отдельное окружение Python 3.12:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-notebook.txt
python -m ipykernel install --user --name hw3-mmda --display-name "Python (HW3)"
```

На Windows активация: `.venv\Scripts\activate`.

Откройте ноутбук в Jupyter, выберите ядро **Python (HW3)** и выполните ячейки сверху вниз. `Data/` должна находиться рядом с ноутбуком; альтернативно ячейка загрузки умеет читать `Data.zip`. Первая ячейка проверяет закреплённые версии зависимостей.

В данном окружении запрещены локальные сокеты, поэтому проверка выполнена в новом процессе IPython последовательно, с поддержкой `%matplotlib inline`, `%%writefile` и сохранением настоящих выводов. Все 24 кодовые ячейки выполнились без ошибок. Это не подстановка заранее подготовленных результатов: модели реально обучены, графики рассчитаны и сохранены в ноутбуке.

## Приложение

```bash
python -m streamlit run wine_app/app.py
```

Подробности — в `wine_app/README.md`. Приложение использует `model.joblib`, `config.json` и `test.csv` относительно файла `app.py`; обучение внутри него не выполняется. В ноутбуке сохранён исходный код приложения: полный повторный запуск также создаёт его файлы.

## Подготовка данных и итог

Из 6 497 исходных строк удалены 1 177 точных повторов **до** разбиения. Осталось 5 320 разных строк: 3 724 в train и 1 596 в test. Иначе одинаковые записи могли бы попасть в обе выборки. Противоречащих друг другу меток для одинаковых признаков нет.

Масштабирование и ресемплинг обучаются только на train. Для выбора порогов из train выделена validation; тестовые метрики не используются при выборе итогового правила.

Итог — `StandardScaler → LogisticRegression` без весов классов, порог **0.2363586094**, выбранный по максимальному precision при validation recall ≥ 0.7.

| Метрика на test | Значение |
|---|---:|
| Precision | 0.4213 |
| Recall | 0.7063 |
| F1 | 0.5277 |
| ROC-AUC | 0.8209 |
| Average precision (PR-AUC в условии) | 0.4848 |

Это компромисс для широкой подборки: обнаружено около 70.6% хороших вин, но доля хороших среди рекомендованных — около 42.1%. Выполнение ограничения на одной выборке не является гарантией для новых партий.

## Проверки

```bash
python tests/check_logreg.py
python -m pytest tests/test_streamlit_app.py -q
```

Проверяются численный градиент, свободный член, история до обновления весов, начальные веса, остановки, устойчивость, SGD и совместимость со sklearn. Для интерфейса прошло **13 тестов**, включая кэширование, крайние пороги, форму и некорректные CSV. Дополнительно приложение проверено с настоящим сохранённым пайплайном и тестовой выборкой.

## Публикация

Приложение опубликовано на **Streamlit Community Cloud**, среда — **Python 3.12**: [открыть Wine Quality](https://wine-quality-3gkpzaqhgfu5jtyl9vo3be.streamlit.app/).

Диаграмма коэффициентов и пояснения отображаются. Во вкладке CSV доступны загрузка файла и скачивание примера; загрузка пользовательского CSV в опубликованной версии отдельно не проверялась. Локальные проверки пакетного режима описаны выше.
